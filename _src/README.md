# MB Sweets website — source

The pages are generated by `build.py` (Python 3, needs Node for reading prices).

- Prices, stock (`off`) and notices come from the shop's shared list `mb-sweets/catalog.js`
  (same file the order menu and billing app use). Pages are built with those prices and
  `site.js` refreshes them live in the browser, so a price change there shows here too.
- `art.py` — Madhubani (Mithila) motifs drawn as SVG: fish pair, lotus, sun, diya, borders.
- `site.css`, `site.js` — copied to `/assets/` by the build.
- `crops.py` + `process.py` — how each photo was cropped and exported to WebP (`assets/img`).
- Build: `python3 build.py` (add `PREVIEW=1` to keep the site hidden from search engines).
- Local preview: `python3 preview_server.py` → http://127.0.0.1:8766 (serves `/mb-sweets/` from the app repo).

Never add a custom domain (CNAME) to this repository: it would move the billing app's
address and hide its saved data on the owner's phone.
- Fonts are WOFF2 (with WOFF fallback). If Python's `brotli` package is missing, put
  `brotli_shim.py` on the path as `brotli.py` — it uses the system libbrotli.
- Photos marked "नमूना फोटो" on the site are sample/AI images; only the `real-*` images are from the shop.
